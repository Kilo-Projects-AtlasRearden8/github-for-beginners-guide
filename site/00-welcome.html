Welcome to GitHub for Beginners

By Asdale Dynamics, LLC — beginner-friendly AI education, books, and guides. For: Dylan Asdale, registered nurse turned AI author and founder of Asdale Dynamics, LLC (Indiana, formed October 2026).

GitHub is a website where people store code, track changes, and work together on projects. You do not need to be a programmer to use it. You do not need the command line. You only need a web browser.

This manual walks you through, step by step:

  1. Creating a GitHub account
  2. Making your first repository
  3. Saving changes with commits
  4. Tracking work with issues
  5. Proposing changes with pull requests
  6. Publishing releases
  7. Publishing a free static site with GitHub Pages

There is also a first-repo checklist and a glossary at the end.

No command line. No secrets. No prior experience needed. Let's get started.
