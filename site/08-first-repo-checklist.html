First-Repo Checklist

Use this checklist the first time you create a repository on GitHub. Print it or copy it into a note.

Before you start

  • [ ] I have a GitHub account and confirmed my email address.
  • [ ] I know whether this repository will be public or private.
  • [ ] I have not included any passwords, API keys, or personal data in my files.

Create the repository

  • [ ] I signed in to github.com.
  • [ ] I clicked + > New repository.
  • [ ] I chose an owner (my personal account).
  • [ ] I gave the repository a short, clear name (lowercase, numbers, hyphens).
  • [ ] I added a one-sentence description.
  • [ ] I chose Public or Private.
  • [ ] I checked Add a README file.
  • [ ] I clicked Create repository.

Add content

  • [ ] I edited the README.md file to explain what the project is.
  • [ ] I added at least one more file (for example, about.md or index.html).
  • [ ] Each file has a commit message describing what was added.

Save changes

  • [ ] Every file I added or edited has a commit.
  • [ ] Commit messages are short and clear (for example, "Add About page").
  • [ ] I checked the Commits page to see my history.

Optional: share and publish

  • [ ] I created an issue to track a task or bug.
  • [ ] I created a branch and opened a pull request to review a change.
  • [ ] I published a release with a version tag (for example, v1.0).
  • [ ] I turned on GitHub Pages and visited my live site (github.io).

Safety check

  • [ ] No secrets or personal data were committed.
  • [ ] I turned on two-factor authentication for my account.
  • [ ] I know how to find my repository settings and Pages settings.
