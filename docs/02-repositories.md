# Repositories

A **repository** (or "repo" for short) is a project folder on GitHub. It holds your files and a history of every change made to them. Think of it like a Google Drive folder that remembers every version of every file.

This chapter shows you how to create a repository, add files, and edit them — all from your browser.

## Create your first repository

1. Sign in to [github.com](https://github.com).
2. Click the **+** icon in the top right and choose **New repository**. You can also go directly to [github.com/new](https://github.com/new).
3. **Owner:** Choose your personal account.
4. **Repository name:** Give it a short, descriptive name. Example: `my-first-repo`. Use lowercase letters, numbers, and hyphens. Avoid spaces.
5. **Description (optional):** A one-sentence summary, like "My first GitHub repository."
6. **Public or private:**
   - **Public:** Anyone can see it. Good for portfolios, open-source projects, and GitHub Pages sites.
   - **Private:** Only you and people you invite can see it.
7. **Initialize this repository with:** Check **Add a README file**. This creates a starting page for your repo so it is not empty.
8. Click **Create repository**.

Your repository now exists with one file: `README.md`.

## What is a README?

The `README.md` file is the front page of your repository. It is what people read first. A good README includes:

- What the project is
- Who made it
- How to use it
- How to contact the author

You will edit it in the next steps.

## Add a new file to your repository

1. On your repository's main page, click **Add file** > **Create new file**.
2. Name the file. Example: `about.md`.
3. Type some content in the editor:

   ```text
   # About This Project

   This is my first repository on GitHub.
   ```

4. Click **Commit changes...** at the top right.
5. In **Commit message**, type a short description, like "Add about page".
6. Choose **Commit directly to the main branch**.
7. Click **Commit changes**.

The file is now saved in your repository.

## Edit an existing file

1. Open the file on GitHub (for example, `README.md`).
2. Click the pencil icon (**Edit this file**) in the top right of the file view.
3. Make your changes.
4. Click **Commit changes...**, write a commit message, and commit.

## Upload files from your computer

1. On your repository page, click **Add file** > **Upload files**.
2. Drag files from your computer onto the page, or choose them manually.
3. Write a commit message and click **Commit changes**.

## Delete a file

1. Open the file on GitHub.
2. Click the trash can icon (**Delete this file**) in the top right.
3. Write a commit message and click **Commit changes**.

## Reminders

- Every save on GitHub is a **commit**. Commits create history, so you can always see who changed what and when.
- A commit message should describe what changed, in plain language. "Fixed typo in README" is better than "update".
- Only you can push changes to your own repository unless you invite collaborators.
